# TaskbarDock — Превращение панели задач Windows в плавающий док «Жидкое стекло»

**TaskbarDock** — легковесная нативная утилита для Windows 10 / 11, которая динамически обрезает стандартную широкую полосу панели задач снизу и превращает её в стильный плавающий «док» (как в macOS) с эффектом «жидкого стекла», гладкими скруглениями углов, возможностью парить поверх окон и отдельной кнопкой вызова быстрых настроек.

---

## 🚀 Основные возможности

1. **Гладкие скругления углов (Anti-Aliasing)**:
   - В отличие от стандартного ступенчатого 1-битного маскирования GDI `SetWindowRgn`, TaskbarDock использует 32-битный полупрозрачный слой с субпиксельным сглаживанием (`Format32bppPArgb`), мягким внешним свечением и тонким внутренним контуром.
   - Скругления выглядят шелковисто-гладкими при любом выбранном радиусе.

2. **Эффект «Жидкое стекло» (Liquid Glass)**:
   - Полупрозрачный стеклянный фон с регулируемым уровнем прозрачности (от 20% до 100%).
   - Спекулярный блик-отражение вдоль верхнего изгиба дока, создающий объемный эффект парящего стекла.

3. **Парение поверх окон (Float Over Windows)**:
   - Док может оставаться поверх обычных и развернутых на весь экран окон.
   - Развернутые окна плавно заполняют всю высоту экрана под доком, не оставляя черных полос.

4. **Автоматическое скрытие в полноэкранных приложениях (Fullscreen Auto-Hide)**:
   - При переходе в полноэкранный режим в играх, видеоплеерах или браузере (F11 / полноэкранное видео YouTube) док автоматически скрывается, не загораживая контент.
   - При возврате к обычному или развернутому окну док мгновенно возвращается на экран.

5. **Отдельная кнопка быстрых настроек справа в доке**:
   - На правой стороне дока расположена элегантная кнопка со значком переключателей/ползунков:
     - **Клик левой кнопкой мыши**: мгновенно вызывает панель быстрых настроек Windows 11 (`Win + A` — громкость, Wi-Fi, Bluetooth, яркость, батарея).
     - **Клик правой кнопкой мыши**: открывает меню быстрого доступа с выбором:
       - Быстрые настройки (`Win + A`)
       - Центр уведомлений и календарь (`Win + N`)
       - Скрытые значки трея (`Win + B`)
       - Настройки TaskbarDock...
   - При наведении курсора кнопка подсвечивается мягким свечением.
   - Клики по значкам приложений проходят напрямую сквозь оверлей без задержек.

6. **Два режима отображения**:
   - **Только док (Рабочая область)** *(по умолчанию)*:
     Остается только компактный блок с Пуском, приложениями и кнопкой быстрых настроек.
   - **Раздельный док (Split Dock)**:
     Блок с приложениями отображается в центре в виде дока, а системный трей (часы, звук, сеть) отображается отдельным аккуратным островком справа.

7. **Графический интерфейс настроек в темном стиле**:
   - Ползунок прозрачности жидкого стекла (в процентах).
   - Ползунок гладкого скругления углов (0–26 px).
   - Горизонтальные отступы по бокам (Padding).
   - Вертикальный плавающий отступ от края экрана (Margin).
   - Чекбоксы: «Док поверх окон», «Скрывать в полноэкранном режиме», «Кнопка быстрых настроек справа», «Автозапуск».
   - Все изменения применяются **на лету (Live Preview)** при перемещении ползунков.

8. **Горячие клавиши и управление**:
   - **`Win + Alt + D`** (или **`Ctrl + Alt + D`**) — быстрое включение / выключение дока в любой момент.
   - Иконка в системном трее с полным контекстным меню.
   - При повторном запуске `TaskbarDock.exe` автоматически открывается окно настроек (защита от дублирования процессов).

9. **Безопасность и чистое восстановление**:
   - При выходе из программы (через пункт «Выход» в трее или при перезагрузке/выключении ПК) панель задач и рабочая область мгновенно возвращаются в исходное стандартное состояние.
   - Системные файлы Windows и `explorer.exe` не модифицируются.

## 📁 Структура проекта

- `TaskbarDock.exe` — готовый скомпилированный исполняемый файл (~62 КБ, полностью нативный, не требует внешних установок или .NET Core).
- `app.ico` — кастомная многослойная иконка приложения.
- `config.ini` — файл настроек.
- `Build.bat` — скрипт для мгновенной сборки из исходников стандартным `csc.exe` Windows .NET.
- Исходный код на C#:
  - `DockOverlayWindow.cs` — 32-битное полупрозрачное окно оверлея (гладкие anti-aliased скругления, эффект жидкого стекла, спекулярный блик и интерактивная кнопка быстрых настроек).
  - `DockEngine.cs` — движок динамического отслеживания значков через UI Automation, обрезки панели задач, работы с WorkArea и автоскрытия в Fullscreen.
  - `SettingsForm.cs` — современный темный интерфейс настроек с Live Preview.
  - `Config.cs` — управление конфигурацией и записью автозапуска в реестр.
  - `NativeMethods.cs` — P/Invoke Win32 API.
  - `Program.cs` — точка входа, Message Loop, горячие клавиши, системный трей.
  - `Logger.cs` — диагностическое логирование (`debug.log`).
